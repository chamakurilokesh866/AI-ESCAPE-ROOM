# docs

- [`report.md`](report.md): source of the short project report (design, implementation, problems encountered, improvements). The main text is 2–3 pages. Appendix A holds live Gemini screenshots; Appendix B is a requirements checklist.
- [`report.pdf`](report.pdf) and [`report.docx`](report.docx): formatted copies for submission.
- [`report.css`](report.css): print stylesheet used to build the PDF with Pandoc and WeasyPrint.
- [`diagrams/`](diagrams/): architecture diagrams for Version 1 (from Mermaid) and Version 2 (print layout).
- [`screenshots/`](screenshots/): screenshots from real Streamlit runs. Prefer the `live_*.png` files (taken with a real Gemini API key). Older `v2_ui_*.png` files are from offline mode and are kept for comparison. The API key never appears in these images.
